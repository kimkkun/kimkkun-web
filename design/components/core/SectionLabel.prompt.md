SectionLabel — the brand's section marker: a zero-padded number in Ochre + a wide-tracked uppercase Latin word. Use it above every section headline instead of an icon.

```jsx
<SectionLabel number="02">PROBLEM</SectionLabel>
<SectionLabel surface="light" number="06">START</SectionLabel>
```

Props: `number` (optional, Ochre) · `children` (the label word) · `surface` dark/light.
Keep words to one short English token — INSIGHT, PROBLEM, VIEW, WORK, PROOF, START.
