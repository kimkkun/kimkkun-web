Input — a single-line text field with a hairline border and an Ochre focus state. Accepts all native `<input>` props.

```jsx
<Input label="이메일" type="email" placeholder="you@store.kr" />
<Input surface="light" placeholder="가게 이름" />
```

Props: `label` (optional uppercase) · `surface` dark/light · plus any native input attribute (`type`, `value`, `onChange`, `disabled`, …).
